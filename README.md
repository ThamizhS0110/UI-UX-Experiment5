# UI-UX Experiment 5: User Pain Point Analysis & New App Concepts

## Aim
To identify user pain points, write clear UX problem statements, choose appropriate research methods, and create user personas for two new apps—Event Booking and Learning/Education—to produce a ready-to-submit UX lab report.

---

## Algorithm

1. **Select Scenarios:**  
   Choose two new conceptual apps: Event Booking and Learning/Education.

2. **Gather Initial Observations:**  
   Review typical user journeys and common complaints (e.g., booking confusion, difficult course navigation).

3. **Identify Pain Points:**  
   List concrete problems users face in each scenario.

4. **Write Problem Statements:**  
   Use format: "[User] needs a way to [achieve goal] because [obstacle], which results in [impact]."

5. **Choose Research Methods:**  
   Select for each scenario (interviews, usability testing, surveys, A/B testing) and justify choices.

6. **Create Personas:**  
   Craft at least two personas (demographics, goals, behaviors, pain points, motivation) per app.

7. **Prepare Deliverables:**  
   Compile the findings into a PDF lab report with images; upload to a GitHub repo.

8. **Summarize Outputs:**  
   List files, repo URL, and conclusion for submission.

---

## Scenario 1: Event Booking App

**Observed User Problems:**
- Users can’t easily find events by date, location, or type.
- The booking flow is cluttered and confusing.
- Lack of status updates post-booking.

**Problem Statement:**
Attendees need a straightforward way to search and book events because the current app’s flow is cluttered, resulting in booking errors and user frustration.

**Selected Research Methods:**
- Usability Testing: Identify confusion in event discovery and booking.
- Online Surveys: Get feedback on event filters and reminders.

**Expected Outcome:**
A more intuitive, guided booking flow with clear filters and instant updates.

**Persona 1:**
- Name: Rahul Singh, Age: 22
- Occupation: College Student, Location: Delhi
- Goals: Find and book music events quickly.
- Pain Points: Booking errors, overwhelmed by too many options.
- Motivation: Attending events with friends, discovering new concerts.

---

## Scenario 2: Learning/Education App

**Observed User Problems:**
- Course navigation is tedious.
- Progress tracking is unclear.
- Users struggle to resume where they left off.

**Problem Statement:**
Learners need a way to easily resume and track their courses because navigation and progress tracking is unclear, which leads to wasted time and disengagement.

**Selected Research Methods:**
- User Interviews: Explore issues with course usability.
- A/B Testing: Compare regular vs. improved progress indicators.

**Expected Outcome:**
Clear progress bars, “resume” button on homepage, and course overview for smoother re-engagement.

**Persona 2:**
- Name: Anjali Mehta, Age: 29
- Occupation: Working Professional, Location: Pune
- Goals: Complete recognized certifications efficiently.
- Pain Points: Losing track of progress, inefficient navigation.
- Motivation: Upskilling, improving career prospects.
